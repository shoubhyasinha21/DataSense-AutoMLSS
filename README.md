# Free DataSense AutomLSS Dataset Analyzer and Trainer

This is a completely free machine learning project.

No paid API is required.

---

## ✨ Features

### 📂 Dataset Analysis

* Upload CSV or Excel dataset
* Show dataset preview
* Show total rows and features
* Show all feature names
* Show feature-wise technical details
* Show missing values
* Show duplicate rows

---

### 📊 Automatic Visualizations

* Distribution Charts
* Correlation Heatmaps
* Feature Analysis Graphs
* Category Distribution Charts
* Interactive Plotly Visualizations
* Fullscreen Charts
* PNG Download Support

---

### 🤖 Machine Learning

* Train classification or regression models
* Compare models
* Show prediction results
* Automatic Best Model Selection
* Model Performance Metrics
* Confusion Matrix
* Classification Report

---

### 📥 Export Options

* Download Excel report
* Download PDF report
* Download best trained model

---
